How to run the app and what to feed it
Project: C:\Users\Raja Reddy\Desktop\PDAgenticAI

Open PowerShell and go to the project first:

cd "C:\Users\Raja Reddy\Desktop\PDAgenticAI"


1. RUN THE THREE BUILT-IN FILES
==============================

Command:

.\.venv\Scripts\python -m app

What you feed:
Nothing. The app already contains Apex, Harbor, and Northwind in app\samples.py.

What you get:
Apex Manufacturing Co.: APPROVE, PD 3.8%, Low, Debt/EBITDA 2.0x, DSCR 1.62x, score 720
Harbor Logistics LLC: REVIEW, PD 7.7%
Northwind Retail Inc.: REJECT, PD 80.7%


2. OPEN THE DESK AND TYPE A LOAN
================================

Command:

$env:DATABASE_URL = "postgresql://postgres:postgre@localhost:5432/credit"
$env:PD_ENV = "local"
.\.venv\Scripts\python -m streamlit run 09_desk\ui.py --server.port 8511

Browser:

http://127.0.0.1:8511

What you feed on the screen, section by section:

1. Loan application
   Business name
   Industry
   Years in business
   Loan purpose
   Loan amount
   Term in years
   Interest rate percent
   Industry outlook

2. Financial statements
   Revenue
   EBITDA
   Interest expense
   Net income
   Current assets
   Current liabilities
   Cash
   Receivables
   Total assets
   Existing debt
   Equity
   Existing annual debt service

3. Credit bureau
   Credit score
   Delinquencies in 12 months
   Bankruptcy on file, yes or no

4. Internal bank data
   Relationship years
   Deposit balance
   Prior loans are current, yes or no

5. Market
   Revenue growth percent
   Officer request

Industry must be one of:
Manufacturing, Wholesale, Logistics, Professional Services, Healthcare, Retail, Construction, Hospitality, Technology, Agriculture

Industry outlook must be one of:
Positive, Stable, Negative

Revenue growth on the desk is a percent. Type 5 for 5 percent.
In a JSON file, revenue_growth is a decimal. Use 0.05 for 5 percent.

Then press Run decision.
That scores the form and saves a copy in data\decisions.db.

To score a file already in PostgreSQL, type the id in the sidebar and press Decide the stored file.
Ids already loaded: apex, harbor, northwind, cedar, summit, ridge.


3. FEED A NEW JSON FILE
=======================

Put one .json file in:

C:\Users\Raja Reddy\Desktop\PDAgenticAI\data\inbox

Then run:

.\.venv\Scripts\python 10_schedule_and_deploy\scheduled_incremental_load.py

The Windows task CreditIncrementalLoad does this every 15 minutes.
After a successful load, the file moves to:

C:\Users\Raja Reddy\Desktop\PDAgenticAI\data\inbox\loaded

5. WHAT YOU GET BACK
====================

A recommendation: APPROVE, REVIEW, or REJECT
A PD, for example 3.8%
A risk grade: Very Low, Low, Medium, High, or Very High
Debt/EBITDA and DSCR
Credit score
Reason lines
A memo
An audit of the agent steps

Stored in PostgreSQL, database credit, schema credit, port 5432:

SELECT * FROM credit.latest_decision ORDER BY application_id;

The other queries are in credit_table_queries.txt.
What each app file does is in app_what_it_does.txt.
